  1. ✅ Now Playing - Shows current playback (all sizes + lock screen)
  2. ✅ Continue Watching - Recent watch history

  4. ✅ Quick Actions - Static shortcuts
  5. ✅ Shabbat Mode - Countdown and times
  6. ✅ Trending News - News summary

  The Core Problem: No Configuration System

  Your widgets are using StaticConfiguration instead of IntentConfiguration,
  which means:

  ❌ Users cannot choose which content to display
  ❌ Cannot add multiple instances of the same widget with different content
  ❌ No "Bayit Plus Widget" with content selection
  ❌ Playlist widget shows ALL playlists (not one selected playlist)
  ❌ No interactive play/pause buttons (intents exist but not wired to widgets)

  In short: The widgets display data but lack user customization and
  interactivity.

  What's Missing vs Your Expectations:

  ┌───────────────────────────────────────────┬─────────────────────────────┐
  │                 Expected                  │        Actual Status        │
  ├───────────────────────────────────────────┼─────────────────────────────┤

  ├───────────────────────────────────────────┼─────────────────────────────┤
  │ Select which playlist to show             │ ❌ NOT IMPLEMENTED          │
  ├───────────────────────────────────────────┼─────────────────────────────┤
  │ Select which channel to display           │ ❌ NOT IMPLEMENTED          │
  ├───────────────────────────────────────────┼─────────────────────────────┤
  │ Interactive play/pause buttons            │ ⚠️ Intents exist, not wired │
  ├───────────────────────────────────────────┼─────────────────────────────┤
  │ Multiple instances with different configs │ ❌ NOT IMPLEMENTED          │
  └───────────────────────────────────────────┴─────────────────────────────┘

  Root Cause:

  All widgets use this:
  StaticConfiguration(kind: kind, provider: Provider())

  They need:
  IntentConfiguration(kind: kind, intent: SelectContentIntent.self, provider:
  IntentProvider())

  showing predetermined content without user control.
