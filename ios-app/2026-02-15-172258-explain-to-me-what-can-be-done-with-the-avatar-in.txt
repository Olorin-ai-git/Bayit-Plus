⏺ Based on my exploration of the Bayit+ codebase, here's a comprehensive
  overview of what can be done with the Avatar in the Zeh Ani (זה אני - "This is
   Me") feature:

  Core Avatar Capabilities

  1. 3D Avatar Creation & Mesh Generation

  - Create from Video Selfie: Generate a personalized 3D avatar from a child's
  video recording
  - Two Generation Methods:
    - ARKit (On-Device): Upload GLB mesh generated directly on iOS device using
  ARKit face tracking
    - Ready Player Me (Cloud): Server-side generation from video selfie
  - Full Rigged 3D Model: Complete with blend shapes for facial animation and
  lip-sync
  - Viewable in 3D: Interactive SceneKit-based viewer with camera controls,
  rotation, and lighting

  2. Magic Mirror (כוס קסמים)

  - Daily Personalized Greetings:
    - Receives bilingual greetings (Hebrew + English translation)
    - Generated fresh daily based on the child's profile
    - Vocabulary of the day for Hebrew learning
  - 3D Avatar Display: Shows the child's animated 3D avatar alongside greetings
  - Audio Greetings: Text-to-speech greetings with lip-sync animation (planned)

  3. Voice Transformation (V2V - Voice-to-Voice)

  - Hebrew Pronunciation Practice: Transform child's voice to match target
  Hebrew phrases
  - Real-time WebSocket Support: Low-latency voice transformation during
  practice sessions
  - Progress Tracking: Monitors improvement scores and session metrics
  - Session History: Review past practice sessions with performance analytics

  4. Highlight Reels (סרטוני הדגשות)

  - Auto-Generated Video Compilations: Creates shareable highlight videos
  featuring the avatar
  - Moment Collections: Compiles special moments into watchable reels
  - Shareable Links: Generate public share tokens for family viewing
  - Thumbnail Generation: Automatic thumbnails for each highlight reel

  5. Live Avatar Overlay

  - Picture-in-Picture Display: Shows animated avatar during live content
  viewing
  - Real-time Blend Shapes: Dynamic facial expressions synced to content
  - Floating Overlay: Non-intrusive 160x160 overlay in corner of screen
  - Integration with Live TV: Works alongside Bayit+ live channel streaming

  6. WhatsApp Contacts Management

  - Family Contact List: Manage contacts the child can communicate with via
  avatar
  - PIN-Protected: Secure contact addition/removal requiring parental PIN
  - Relationship Tracking: Define relationships (grandparent, friend, etc.)
  - Multi-language Support: Specify preferred language per contact

  7. Feedback Inbox

  - Interaction History: View feedback from avatar interactions
  - Learning Progress: Track educational feedback and achievements
  - Parental Monitoring: Review child's interactions with avatar features

  8. Avatar Settings & Management

  - Re-record Avatar: Capture new selfie video to update avatar appearance
  - Mesh Status Monitoring: Track generation status (pending → generating →
  rigging → ready)
  - Delete Avatar: Revoke biometric consent and remove avatar data
  - Metadata Display: View blend shape count, vertex count, bone count

  Security & Privacy Features

  Biometric Consent System

  - Three Consent Types:
    - mesh_generation: Required for creating 3D avatar
    - voice_v2v: Required for voice transformation
    - latent_features: For advanced AI features
  - PIN Protection: All biometric operations require 6-digit parental PIN
  - Revocable: Consent can be withdrawn at any time
  - Per-Profile: Consent tracked separately for each child profile

  Technical Specifications

  - Mesh Format: glTF Binary (.glb) with blend shapes
  - Blend Shapes: Includes facial expressions like mouthOpen, eyeBlink, etc.
  - Storage: Secure Google Cloud Storage with signed URLs (time-limited access)
  - Credits System: Uses Beta 500 AI credits for generation operations
  - Credit Costs:
    - 3D Mesh (ARKit): Configurable credit cost
    - V2V Transform: Per-session credit usage
    - Highlight Reel: One-time generation cost

  User Flow

  1. Navigate to Zeh Ani Hub → Access from main app navigation
  2. Grant Biometric Consent → PIN-protected consent for avatar features
  3. Create Avatar → Record video selfie for mesh generation
  4. Wait for Processing → Cloud generation or instant ARKit upload
  5. Explore Features:
    - View daily Magic Mirror greetings
    - Practice Hebrew with V2V voice transformation
    - Generate and share highlight reels
    - Manage trusted contacts
    - Review feedback history

  The avatar becomes a personalized, interactive companion for the child's
  learning and entertainment experience on Bayit+, with strong parental controls
   and privacy protections built-in.
