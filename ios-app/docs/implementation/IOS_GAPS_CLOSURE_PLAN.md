# Implementation Plan: Close All iOS Gaps -- Subtitles, Dubbing, Trivia

**Date:** 2026-02-08
**Status:** Ready for Implementation
**Reviewer Approvals:** All agents signed off

## Context

The Bayit+ iOS app has partial implementations for Interactive Subtitles, Live Dubbing, and Trivia. A gap analysis plus user request identified **21 missing features** across these pillars. The backend APIs and web/mobile implementations are fully complete. This plan closes every gap in iOS with fully functional code -- no stubs, mocks, or placeholders. All files under 200 lines.

## Reviewer Feedback Addressed

- **Code Reviewer**: Split large ViewModels into focused services. ShoreshParser uses protocol for testability.
- **UI/UX Designer**: Shoresh highlight color uses amber (#FFA500) for WCAG AA contrast. Trivia overlay positioned ABOVE subtitle zone when subtitles active. Mode descriptions added to picker.
- **Security Expert**: WebSocket auth-first with error handling. Token refresh on reconnect. Cache TTL enforcement.
- **iOS Developer**: Actor for file I/O confirmed. Hebrew final forms documented. URLSession lifecycle fix.
