  - Use Case: Real-time voice agents with custom avatar images

  - Capability: Animate static images with lip-sync (24fps, film-grade quality)

    - Emotion-aware expression matching audio tone

  - ⚠️ Important: OmniHuman API access is through third-party providers, not
  directly from ElevenLabs:
    - AI/ML API
    - Eachlabs
    - BytePlus Official

  OmniHuman 1.5 via Third-Party APIs:
  Input:
  - Reference image (URL or Base64)
  - Audio file (max 30 seconds)

  Output:
  - Synchronized video (up to 30 seconds)
  - Resolution: 1024×1024
  - Format: MP4 with full-body animation

  ElevenLabs Conversational AI Avatar:
  Endpoint: POST /v1/convai/agents/{agent_id}/avatar
  Headers: xi-api-key
  Body: image file (multipart/form-data)
  Use: Static avatar image for voice agent widget
