SECTION 2: BACKEND API INVENTORY (22 endpoints + 1 WebSocket)
##############################################################################

CHANNELS (3 endpoints):
  GET  /api/channels                              -- List all active channels
  GET  /api/channels/{channel_id}                 -- Get channel details
  GET  /api/channels/{channel_id}/stream          -- Get signed stream URL

SUBTITLES (5 endpoints):
  POST /api/live-subtitles/ingest                 -- Ingest subtitle segment
  GET  /api/live-subtitles/{channel_id}/latest    -- Get latest subtitle cue
  GET  /api/live-subtitles/{channel_id}/webvtt    -- Get WebVTT file
  GET  /api/live-subtitles/{channel_id}/stream    -- SSE real-time stream
  POST /api/live-subtitles/{channel_id}/end-session -- End subtitle session

DUBBING (5 endpoints):
  GET  /api/dubbing/languages                     -- List available languages
  POST /api/dubbing/sessions                      -- Create dubbing session
  POST /api/dubbing/sessions/{id}/segments        -- Submit audio segment
  GET  /api/dubbing/sessions/{id}/segments        -- Get session segments
  POST /api/dubbing/sessions/{id}/end             -- End dubbing session

CATCHUP (4 endpoints):
  GET  /api/catchup/{channel_id}/epg              -- Get EPG schedule
  GET  /api/catchup/{channel_id}/now-playing       -- Get current program
  GET  /api/catchup/{channel_id}/recordings        -- List catchup recordings
  GET  /api/catchup/recordings/{id}/stream         -- Get catchup stream URL

TRIVIA (4 endpoints + 1 WebSocket):
  GET  /api/trivia/{channel_id}/round              -- Get/create active round
  POST /api/trivia/{id}/rounds/{rid}/answer        -- Submit answer
  GET  /api/trivia/{id}/rounds/{rid}/leaderboard   -- Round leaderboard
  GET  /api/trivia/{channel_id}/leaderboard        -- Channel leaderboard
  WS   /api/trivia/{channel_id}/ws                 -- Real-time game session

External Services:
  - OpenAI (gpt-4o): Subtitle translation, trivia question generation
  - ElevenLabs: Text-to-Speech dubbing synthesis
  - Google Cloud Storage: Dubbing audio segments, catchup recordings
  - Firebase Auth: JWT token verification for all endpoints
  - MongoDB Atlas: All document storage via Beanie ODM
  - Redis: Caching and rate limiting

Channel Model Feature Flags (per channel in MongoDB):
  - dubbing_enabled: bool
  - subtitles_enabled: bool
  - trivia_enabled: bool
  - catchup_enabled: bool
  - catchup_days: int (retention period)

##############################################################################
SECTION 6: BACKEND ISSUES FOUND DURING INVESTIGATION
##############################################################################

1. TRIVIA WEBSOCKET AUTH GAP: /api/trivia/{channel_id}/ws has NO Firebase
   authentication. Client-provided user_id is spoofable. All other endpoints
   properly require get_current_user.

2. SUBTITLE INGEST RATE LIMIT BUG: live_subtitles.py passes the Request
   class instead of the request instance to the rate limiter.

3. TRIVIA LEADERBOARD PERIOD BUG: _update_leaderboard updates all three
   period types (daily/weekly/all_time) with the same aggregate data.
   No date-range filtering distinguishes daily from weekly.

4. DUBBING COST EXPOSURE: No per-user session limits for dubbing. Each
   segment triggers both OpenAI and ElevenLabs API calls.

5. CATCHUP CLEANUP MISSING: No background task deletes expired recordings
   (available_until field is set but never enforced).

6. CACHE INVALIDATION: No admin API to invalidate cached channel data
   after updates.

These should be addressed before or alongside the frontend parity work.
