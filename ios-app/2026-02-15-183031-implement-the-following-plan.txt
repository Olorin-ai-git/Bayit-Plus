│ VOD Avatar Interaction Implementation Plan                                   │
│                                                                              │
│ Context                                                                      │
│                                                                              │
│ Feature Goal: Enable Zeh Ani avatars to interact with movie characters       │
│ during VOD playback, with AI-generated animated character responses and the  │
│ ability to save short reels of these interactions.                           │
│                                                                              │
│ Why This Feature: Transforms passive VOD consumption into active engagement. │
│  Children's avatars can "talk to" movie characters, making content more      │
│ memorable and shareable. Creates viral "Saba Loop" moments when families     │
│ share reels of kids interacting with favorite characters.                    │
│                                                                              │
│ User Decisions:                                                              │
│ - Content Scope: Curated content only (manually tagged interactive moments)  │
│ - Trigger: Automatic prompts at predefined moments (video auto-pauses)       │
│ - Reel Length: 30 seconds (consistent with existing Highlight Reels)         │
│ - Privacy: Private by default, opt-in sharing                                │
│                                                                              │
│ Technical Foundation:                                                        │
│ - Existing Live Avatar Overlay component (PiP 3D avatar during playback)     │
│ - Existing Highlight Reel service (FFmpeg + GCS storage)                     │
│ - ElevenLabs TTS integration (already in backend)                            │
│ - Creatify Aurora API (new) for animating character frames                   │
│                                                                              │
│ Architecture: Hybrid Client-Server Approach                                  │
│                                                                              │
│ Live Interaction Flow (Client-Side)                                          │
│                                                                              │
│ 1. Video auto-pauses at predefined interactive moment                        │
│ 2. User's avatar appears with "Talk to [Character]" prompt                   │
│ 3. User speaks/types → sent to backend                                       │
│ 4. Backend generates character dialogue → ElevenLabs TTS → Creatify animates │
│  character frame                                                             │
│ 5. Animated character response plays in overlay                              │
│ 6. Browser MediaRecorder captures composite (optional: instant preview)      │
│                                                                              │
│ Reel Generation (Server-Side)                                                │
│                                                                              │
│ 1. User selects interaction moments to save                                  │
│ 2. Backend extracts video segments via FFmpeg                                │
│ 3. Re-renders avatar overlays with animated character responses              │
│ 4. Composites all elements: video + avatar + animated character              │
│ 5. Uploads final reel to GCS with share token                                │
│                                                                              │
│ Benefits: Immediate feedback (client-side), high-quality shareable output    │
│ (server-side), reuses existing infrastructure.                               │
│                                                                              │
