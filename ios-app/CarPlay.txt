│ Context                                                                      │
│                                                                              │
│ Bayit+ is a premium Jewish streaming platform with Live Radio, Podcasts,     │
│ Audiobooks, and Live TV. Users driving with CarPlay-enabled vehicles         │
│ currently cannot access any audio content. This implementation adds full     │
│ CarPlay audio support, allowing users to browse and play all audio content   │
│ types (Live Radio, Podcasts, Audiobooks, Live TV audio-only) directly from   │
│ their car's CarPlay interface.                                               │
│                                                                              │
│ The app already has a mature audio playback stack (MediaPlayer,              │
│ AudioSessionService, NowPlayingService, RemoteCommandService,                │
│ AudioPlaybackManager) and a feature flag (isCarPlayEnabled). No CarPlay code │
│  exists yet.                                                                 │
│                                                                              │
│ Entitlement Setup (Manual Step)                                              │
│                                                                              │
│ Before the code works on a real device, you must:                            │
│ 1. Go to https://developer.apple.com/carplay and submit a request for the    │
│ "CarPlay Audio" entitlement                                                  │
│ 2. Describe the app: "Bayit+ is a premium Jewish streaming platform offering │
│  live Israeli radio stations, podcasts, and audiobooks"                      │
│ 3. Once approved (can take days/weeks), go to Certificates, IDs & Profiles > │
│  Identifiers > tv.bayit.plus                                                 │
│ 4. Enable "CarPlay Audio" capability                                         │
│ 5. Regenerate provisioning profile and download to Xcode                     │
│ 6. The code below will work immediately on the CarPlay Simulator without     │
│ waiting for approval                                                         │

│ Architecture Notes                                                           │
│                                                                              │
│ - CarPlay runs as a separate UIScene alongside the main app scene. Both can  │
│ be active simultaneously.                                                    │
│ - The CarPlay scene creates its own RepositoryProvider (lightweight - just   │
│ protocol wrappers over APIClient) and shares the auth token via keychain.    │
│ - MediaPlayer is a shared singleton - if audio is playing on the phone and   │
│ the user connects CarPlay, the Now Playing state transfers automatically     │
│ because MPNowPlayingInfoCenter is system-level.                              │
│ - CPNowPlayingTemplate.shared reads directly from MPNowPlayingInfoCenter -   │
│ no custom UI needed for the player screen.                                   │
│ - All content fetches go through existing repositories (no new API endpoints │
│  needed).                                                                    │
│ - The 200-line file limit is respected by splitting into 4 focused files.    │
