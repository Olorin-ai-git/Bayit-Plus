⏺ Here's a summary of the guide and what it means for the Olorin ecosystem:

  ---
  What Are Claude Skills?

  Skills are instruction folders (SKILL.md + optional scripts/references/assets)
   that teach Claude repeatable workflows. They work across Claude.ai, Claude
  Code, and the API. Three levels of progressive disclosure minimize token
  usage:

  1. YAML frontmatter - Always loaded, tells Claude when to activate
  2. SKILL.md body - Loaded when relevant, contains full instructions
  3. Linked files - Referenced on-demand (scripts, docs, templates)

  Three Skill Categories

  Category: Document/Asset Creation
  Purpose: Consistent, high-quality output
  Example: Generate reports, designs, code
  ────────────────────────────────────────
  Category: Workflow Automation
  Purpose: Multi-step processes with validation
  Example: Sprint planning, onboarding flows
  ────────────────────────────────────────
  Category: MCP Enhancement
  Purpose: Workflow layer on top of tool access
  Example: Coordinate multiple API calls

  Five Key Patterns

  1. Sequential Workflow - Step-by-step with validation gates
  2. Multi-MCP Coordination - Orchestrate across services (Figma + Drive +
  Linear + Slack)
  3. Iterative Refinement - Draft, validate, improve loops
  4. Context-Aware Tool Selection - Decision trees based on input
  5. Domain-Specific Intelligence - Embed specialized knowledge (compliance,
  rules)
