⏺ Both builds pass. Here's what changed:

  GlassHeroCarousel.swift - two fixes:

  1. Crossfade instead of offset scroll: Replaced the HStack + offset(x:)
  approach with a ZStack that conditionally renders only the current item using
  .transition(.opacity). Now last→first transitions smoothly fade instead of
  "rushing" backwards through all cards.
  2. Removed .focusSection() + .onMoveCommand: These were intercepting all
  directional input, preventing focus from moving between "Watch Now" and "More
  Info" buttons. Now the buttons receive natural D-pad focus movement.
  3. Focusable page indicator dots: Each dot is now a Button with @FocusState
  tracking. When the user navigates down to the dots and moves left/right
  between them, pages change automatically on focus. This provides manual page
  control without interfering with hero button focus.
